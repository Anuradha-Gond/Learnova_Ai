# Learnova AI — End-to-End (E2E) Test Specifications

This directory contains the end-to-end user journey test specifications for Learnova AI:

1. **Authentication Flow**: Student registration $\to$ session cookie verification $\to$ redirect to dashboard.
2. **Document Ingestion**: Drag & drop PDF $\to$ progress tracking $\to$ workspace view.
3. **AI Study Interaction**: Generate summary $\to$ ask doubt with grounded citation $\to$ test concept simplifier.
4. **Quiz Attempt & Evaluation**: Generate 10-question quiz $\to$ answer with timer $\to$ server scoring $\to$ scorecard review.
5. **Weak-Topic Diagnostics**: Confirm weak topic card creation for scores $< 65\%$.
